    Without flashing from the browser

    Download configuration image and write it yourself: 

    esptool.py write_flash 0x9000 nvs.bin

    Good to know

    • Running more than one device on the same network or broker means hostname, Bluetooth name, client ID and topic pattern have to differ. Two devices sharing a client ID keep kicking each other off the broker, and a shared topic pattern mixes both of them into one tree. The device name takes care of the first three, the topic pattern is yours to set — something like Divoom-Livingroom with divoom/livingroom/%s works well.
    • Values you leave empty fall back to the defaults the firmware was built with.
    • Update configuration only: the dialog offers to erase the device first. Leave that checkbox empty — ticking it wipes the firmware and the device stops booting until you run a full install again.
